FCrDNS Verification

All egress IPs used by Merihelp Bot have PTR records resolving to *.crawler.merihelp.bot. Forward-confirmed reverse DNS (FCrDNS) lookups will resolve back to the same IP, confirming authenticity.

Purpose

Merihelp Bot is an automated monitoring crawler operated by Merihelp. It accesses publicly available data published by ERCOT (Electric Reliability Council of Texas) to track grid conditions, energy pricing, and market data.

Target Data Sources

ERCOT public market data feeds, real-time grid status, LMP pricing, generation capacity reports, and load forecasts available at ercot.com and its public data APIs.

Data collected is used exclusively for internal monitoring, alerting, and analytics. Merihelp Bot does not scrape personal data, login-protected content, or any resource that has not been made publicly available by ERCOT.

Crawl Policy

Merihelp Bot is designed to be a polite, low-impact crawler. The following request headers are sent on every request:

User-Agent: Merihelp/1.0 (+https://merihelp.bot/bot) From: bot@merihelp.bot Accept: application/json, text/html, text/xml, */* Accept-Encoding: gzip, deflate, br # Crawl-delay is honored per robots.txt; default min is 5s

Opt-Out / Rate Limiting

To block Merihelp Bot, add User-agent: Merihelp with Disallow: / to your robots.txt. To request custom rate limits or a complete block, contact us at the address below.
